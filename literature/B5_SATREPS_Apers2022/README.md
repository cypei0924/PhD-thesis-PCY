# B5: SATREPS Japan-Indonesia peat monitoring sites (11 sites)

**Status:** No public data

**Data source:** [SATREPS 'fire2015' page (offline)](http://kalimantan88.sakura.ne.jp/fire2015/fire2015home.html)

**Paper:** Apers et al. 2022, JAMES 14, https://doi.org/10.1029/2021MS002784 (Open; saved in D9_PEATCLSM_Trop_Apers2022/paper/)

> Data availability: 'Groundwater level and eddy covariance data used for evaluation are available at the sources indicated in Table B1.' For SATREPS: 'publicly available, frequently updated water level data ... that was manually digitized'.

**How the paper used the data:** Apers et al. digitised the SATREPS water-level graphs for 11 sites (natural and drained, 2012-2020) and used them, with the other Table B1 sites, to evaluate PEATCLSM_Trop water levels (see D9).

- kalimantan88.sakura.ne.jp no longer resolves (DNS), so the graphs cannot be re-digitised; the site list with coordinates and years is in EXPANDED_2006-2026.xlsx (B5).

Full details: `../DATA_SUMMARY.md`. Papers go in `paper/` (git-ignored); run `../download_papers.py B5`.
