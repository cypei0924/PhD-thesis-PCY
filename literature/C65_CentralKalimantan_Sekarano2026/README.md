# C65: 26 GWL stations in Pulang Pisau and Palangka Raya (Sentinel-2 + LSTM), Central Kalimantan

**Status:** No public data

**Data source:** [Preprint](https://doi.org/10.2139/ssrn.7439436)

**Paper:** Sekarano et al. 2026, SSRN preprint, https://doi.org/10.2139/ssrn.7439436 (Abstract only (closed access or the publisher blocked the download); full text not read)

> Data availability: Not read.

**How the paper used the data:** 21,954 GWL observations from 26 quality-controlled stations (December 2018 - December 2022) combined with Sentinel-2 bands and moisture indices; LSTM reached R2 0.89 and RMSE about 0.13 m and mapped the 2019 dry-season drawdown (abstract).

- Station network not named in the abstract; with BRIN (Sulaiman) and Hirano as co-authors it is probably SIPALAGA (your A25/A27, B1).
