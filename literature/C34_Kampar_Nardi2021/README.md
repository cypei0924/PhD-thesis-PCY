# C34: Kampar Peninsula conservation forest (Pelalawan)

**Status:** No public data

**Data source:** [Paper](https://doi.org/10.29244/jpsl.11.3.442-452)

**Paper:** Nardi et al. 2021, JPSL 11, https://doi.org/10.29244/jpsl.11.3.442-452 (Open; downloaded to paper/)

> Data availability: No data availability statement.

**How the paper used the data:** Solinst Levelogger 3001 recording every 30 min (January-December 2020; mean -0.32 +/- 0.18 m) plus manual piezometer readings at three conservation-forest points at each N2O sampling; GWL entered the N2O regression models.


Full details: `../DATA_SUMMARY.md`. Papers go in `paper/` (git-ignored); run `../download_papers.py C34`.
