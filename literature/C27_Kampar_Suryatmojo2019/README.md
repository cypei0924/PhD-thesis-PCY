# C27: Zamrud NP forest, burnt peat and mixed plantation (Siak, Kampar Peninsula landscape)

**Status:** No public data

**Data source:** [Paper](https://doi.org/10.1088/1755-1315/361/1/012034)

**Paper:** Suryatmojo et al. 2019, IOP Conf. Ser.: Earth Environ. Sci. 361, https://doi.org/10.1088/1755-1315/361/1/012034 (Open; downloaded to paper/)

> Data availability: No data availability statement.

**How the paper used the data:** Automatic GWL sensors and mini weather stations for 4 months (rain events of April-June 2018) in primary forest (Zamrud National Park), an ex-fire site and a community mixed plantation in Sungai Rawa village, Siak; GWL rise per rain event was analysed.

- Coordinates (Maryani 2020, same stations): forest 0 42 54 S, 102 13 35 E; burnt 0 52 16 S, 102 20 22 E; mixed plantation 0 52 35 S, 102 20 41 E. The sites are in Siak regency, not Kampar.

Full details: `../DATA_SUMMARY.md`. Papers go in `paper/` (git-ignored); run `../download_papers.py C27`.
